# Streamlit 実装規約

## 全体
- 要件を満たす最小限の実装にする。不要な抽象化やクラス階層を作らない
- 起動は `streamlit run app.py` のみで動くこと

## ディレクトリの役割
- app.py：エントリーポイント、画面の切替
- i18n.py：UI文言の辞書（ja / en）
- quiz.py：出題・採点ロジック（Streamlitに依存しない純粋な関数にする）
- db.py：SQLiteの読み書きはすべてここに集約する
- data/questions.json：問題データ（アプリからは読み取り専用）

## 状態管理
- 画面遷移やクールの進行状態は st.session_state で管理する
- session_state のキー名は1か所（app.py 冒頭など）で初期化する
- 回答確定後に再実行で二重登録されないよう、回答済みフラグで制御する

## 文言
- 画面に出す文字列は直書きせず、必ず i18n 辞書から取得する
- 問題・選択肢・解説は、選択中の言語のフィールド（ja / en）を表示する

## DB
- 画面のコードから直接SQLを書かない。db.py の関数を呼ぶ
- テーブル定義を変える場合は、既存データを壊さない方法を提示してから行う

## テスト
- 採点（single / multiple）と出題（重複なし、モード別の選び方、件数不足時の挙動）は pytest でテストする
- UIのテストは不要
